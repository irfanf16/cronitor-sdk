# Security Policy

## Reporting a vulnerability

Please report security issues to https://github.com/irfanf16/cronitor-sdk/security/advisories/new.

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/irfanf16/cronitor-sdk/issues

## Scope

This policy applies to the generated Irfan SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the Cronitor public API, generated by
Irfan. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
